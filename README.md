# 🏠 Airbnb MERN Clone

A full-stack Airbnb-style web application built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. The platform allows users to browse rental listings, view property details, and manage listings through a clean and responsive interface. It demonstrates core full-stack concepts such as **RESTful APIs, CRUD operations, database integration with MongoDB, and frontend–backend communication**.
